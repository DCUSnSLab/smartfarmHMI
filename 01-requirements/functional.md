# 01-1 · 기능 요구사항

## 0. 표기 규칙

- 기능 ID: `FR-<번호>` (1~31, 원본 기능설계 문서 번호와 동일)
- **담당 영역**: `HMI`(웹앱+서버가 직접 구현) / `엣지`(제어·판단 로직, 개발 범위 밖 — 결과만 수신) / `공통`(설정·표시는 HMI, 실행은 엣지). "공통"은 항목마다 반복 설명하지 않고 이 정의를 그대로 적용한다.
- **데이터소스**: `SIMULATED`(2차년도는 실물 엣지가 없어 임의 데이터 생성기가 대신 응답) / `N/A`(엣지 시뮬레이션 데이터에 의존하지 않는 기능 — 순수 HMI 관리·입력·플랫폼 기능이거나, 음성·LLM처럼 엣지가 아닌 다른 외부 시스템에 의존하는 기능)

---

## 1. 로봇 제어

### FR-01 로봇 작업데이터 로깅
- 설명: 단위작업별 성공 여부 및 작업량 로깅 (수확, 적엽 등)
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 작업 이력을 서버가 수신·저장하고 웹앱에서 조회한다.

### FR-02 다중 로봇 제어
- 설명: 군집 제어 및 이종 로봇 제어
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 웹앱은 제어 요청 UI만 제공하고, 서버가 명령을 규격화해 엣지로 전달한다.

### FR-03 로봇임무 스케줄링
- 설명: 각 로봇의 시간별 운반경로 지정 (배송물 위치, 배송될 위치)
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 임무 등록·조회 UI를 제공하고 서버가 저장한다.

### FR-04 로봇상태 모니터링
- 설명: 로봇 위치, 속도, 전원, 이상여부 주기적 모니터링
- 담당 영역: HMI
- 데이터소스: SIMULATED

### FR-05 로봇 센서데이터 로깅
- 설명: 로봇 영상데이터 로깅 (생육상태 판별용)
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 영상 메타데이터를 수신·저장하고 조회 UI를 제공한다. 원본 영상은 목데이터로 대체한다.

### FR-06 로봇 자동충전기능
- 설명: 로봇 자동충전 지시, 다중 로봇 운용 시 충전 스케줄링
- 담당 영역: 엣지
- 데이터소스: SIMULATED

### FR-07 로봇 추가/삭제 기능
- 설명: 관리 대상 로봇의 추가 또는 삭제
- 담당 영역: HMI
- 데이터소스: N/A

## 2. 생육기 제어

### FR-08 생육환경 모니터링
- 설명: 온도/습도/양분/조도/소모전력 주기적 모니터링 (센서 정상작동여부 포함)
- 담당 영역: HMI
- 데이터소스: SIMULATED

### FR-09 생육상태 모니터링
- 설명: 영상 기반 생육 상태(성장률, 병충해 유무, 수확시기) 모니터링
- 담당 영역: 공통
- 데이터소스: SIMULATED
- 비고: 영상 수집은 엣지, 분석 결과 표시는 HMI가 담당한다. AI 분석 자체는 외부 연동 훅으로 처리한다.

### FR-10 생육기 수동제어
- 설명: 생육기의 온도/습도/양분/조도를 수동 설정값에 맞게 제어
- 담당 영역: 공통
- 데이터소스: SIMULATED

### FR-11 생육기 자동제어
- 설명: 성장단계에 맞는 온도/습도/양분/조도 자동 설정
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 웹앱은 자동 모드 On/Off와 결과 확인 UI만 제공한다.

### FR-12 AI기반 생육기 제어
- 설명: 생육조건 유지 시 전력효율을 극대화하는 AI 제어
- 담당 영역: 엣지
- 데이터소스: SIMULATED
- 비고: 웹앱은 설정 UI만 제공하고, AI 판단 로직은 외부 연동 훅으로 처리한다.

### FR-13 생육기 추가/삭제 기능
- 설명: 관리 대상 생육기의 추가 또는 삭제
- 담당 영역: HMI
- 데이터소스: N/A
