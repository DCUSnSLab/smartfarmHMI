# 04-1 · 2차년도 로드맵과 현재 개발 범위

## 1. 일정 제약

- 스마트팜 실물 세팅이 **8월** 완료 예정이다.
- 로봇공학과 결과발표는 **2027년 1월**이다 (기존 로드맵의 통합테스트·데모 시기와 일치).
- 따라서 우리 담당 기능은 **8월까지 완성되고, 실 하드웨어와 연동 가능한 상태**여야 한다. 이후 9월~1월은 실제 연동·안정화·나머지 기능 확장 기간이다.

## 2. 2차년도 데모 목표

- 음성 인식을 통한 식물공장 제어
- 웹앱을 통한 식물공장 제어

상세 시나리오는 아직 확정되지 않았다 (OPN-11).

## 3. 2차년도 로드맵

| 시기 | 내용 |
|---|---|
| 5월 | 시스템 아키텍처 설계 (애플리케이션 서버/미들웨어 서버 분리 포함), 통신 규격 초안, DB 스키마, 파레트 반출-작업-반납 흐름 모델링 |
| 6월 | 애플리케이션 서버·미들웨어 서버 프레임워크 구축, 임의 데이터 생성기 구현 |
| 7월 | 모니터링 대시보드·제어 UI 개발, 엣지(시뮬레이터)-미들웨어 서버-애플리케이션 서버-웹앱 전체 흐름 연동 테스트 |
| **8월** | **스마트팜 실물 세팅 완료에 맞춰 실 하드웨어 연동** (임의 데이터 생성기 → 실제 엣지로 교체) |
| 9~12월 | 음성인식 엔진 연동, 나머지 기능(양액·급수·방재 UI, LED, 탱크 수위 등) 확장·안정화 |
| 1월 | 통합 테스트, 로봇공학과 결과발표 연계 데모 |

## 4. 현재 개발 범위

1. 임의 센서/로봇상태 데이터 생성기 구현 (`03-architecture/communication-interface.md`의 메시지 스키마 기준)
2. 미들웨어 서버가 데이터를 수신·저장 (FR-01, FR-04, FR-08, FR-16)
3. 애플리케이션 서버·웹앱에서 데이터 조회 화면 구현 (FR-08 생육환경 모니터링, FR-04 로봇상태 모니터링 우선)

이 흐름이 검증되면 제어 명령 방향(웹앱 → 애플리케이션 서버 → 미들웨어 서버 → 엣지, FR-10 등)과 나머지 기능을 확장한다.
