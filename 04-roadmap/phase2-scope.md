# 04-1 · 2차년도 로드맵과 현재 개발 범위

## 1. 2차년도 데모 목표

- 음성 인식을 통한 식물공장 제어
- 웹앱을 통한 식물공장 제어

상세 시나리오는 아직 확정되지 않았다 (OPN-11).

## 2. 2차년도 로드맵

| 시기 | 내용 |
|---|---|
| 5~6월 | 시스템 아키텍처 설계, 통신 프로토콜 정의, DB 스키마 설계, 제어 API 명세 |
| 7~8월 | 서버 프레임워크 구축, 임의 데이터 생성기 구현 |
| 9~10월 | 모니터링 대시보드, 생육기 수동제어 UI, 음성인식 엔진 연동 |
| 11~1월 | 통합 테스트, 데모 준비 |

## 3. 현재 개발 범위

1. 임의 센서/로봇상태 데이터 생성기 구현 (`03-architecture/communication-interface.md`의 메시지 스키마 기준)
2. 서버가 데이터를 수신·저장 (FR-01, FR-04, FR-08, FR-16)
3. 웹앱에서 데이터 조회 화면 구현 (FR-08 생육환경 모니터링, FR-04 로봇상태 모니터링 우선)

이 흐름이 검증되면 제어 명령 방향(웹앱 → 서버 → 엣지, FR-10 등)과 나머지 기능을 확장한다.
