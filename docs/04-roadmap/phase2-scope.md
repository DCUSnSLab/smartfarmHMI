# 04-1 · 2차년도 로드맵과 현재 개발 범위

## 1. 일정 제약

- 스마트팜 실물 세팅이 **8월** 완료 예정
- 로봇공학과 결과발표는 **2027년 1월**
- 따라서 우리 담당 기능(31개) 개발은 **8월까지 끝내고**, 이후에는 실제 엣지로 교체·연동 검증을 진행한다.

## 2. 2차년도 데모 목표

- 음성 인식을 통한 식물공장 제어
- 웹앱을 통한 식물공장 제어

상세 시나리오는 아직 확정되지 않았다 (OPN-11).

## 3. 2차년도 로드맵

시스템 기반 설계 및 핵심 구현

**5~6월 : 시스템 아키텍처 설계**
- 통신 프로토콜 정의 (ROS2↔WebSocket)
- DB 스키마 설계 (센서·영상·로봇·생육)
- 제어 API 명세 (타 연구실 인터페이스 합의)

**7~8월 : 백엔드 코어 + 엣지 개발**
- 미들웨어 서버 프레임워크 구축
- 엣지 컨트롤러: 통신 브리지 + 디바이스 매니저
- 센서/시설 드라이버 + 데이터 버퍼 구현

**9~10월 : 프론트엔드 + 음성인식 모듈**
- 모니터링 대시보드 MVP (환경 데이터)
- 생육기 수동제어 UI + 음성인식 엔진 통합
- 엣지-미들웨어 데이터 동기화 테스트

**11~1월 : 통합 테스트 + 데모**
- 식물공장 모듈 연동 (엣지→미들웨어→웹앱)
- 데모: 음성/웹앱 → 식물공장 제어
- 안전 감시 모듈 기초 구현

## 4. 현재 개발 범위

1. 임의 센서/로봇상태 데이터 생성기 구현 (`03-architecture/communication-interface.md`의 메시지 스키마 기준)
2. 미들웨어 서버가 데이터를 수신·저장 (FR-01, FR-04, FR-08, FR-16)
3. 애플리케이션 서버·웹앱에서 데이터 조회 화면 구현 (FR-08 생육환경 모니터링, FR-04 로봇상태 모니터링 우선)

이 흐름이 검증되면 제어 명령 방향(웹앱 → 애플리케이션 서버 → 미들웨어 서버 → 엣지, FR-10 등)과 나머지 기능을 확장한다.
