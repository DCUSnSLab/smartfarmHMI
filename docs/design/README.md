RISE 피지컬 AI 기반 스마트농업 생태계 구축 사업 2차년도 · 웹앱 기반 스마트팜 HMI 프로토타입

> **이 전달본은 요구사항 정합화 이전에 만들어졌다.** 2026-07-29 요구사항·설계 문서 개편 과정에서 명칭·문구를 일부 수정했고, 구조·동작 변경이 필요한 항목은 [design-change-spec.md](./design-change-spec.md)에 정리했다. 구현 착수 전 반드시 그 문서를 함께 볼 것.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `팜온 스마트팜 HMI v3 (단독실행).html` | **더블클릭으로 바로 실행.** 외부 파일·인터넷 없이 동작하는 단일 파일. 기획·검토 공유용 |

| `support.js` | 원본(`.dc.html`) 실행에 필요한 런타임. 같은 폴더에 함께 있어야 함 |

원본을 열 때는 `.dc.html`과 `support.js`를 **같은 폴더**에 두고 `.dc.html`을 브라우저로 열면 됩니다.

### ⚠️ 단독실행본 재출력 필요

**현재 `.dc.html`과 단독실행본의 내용이 어긋나 있습니다.** 2026-07-29 수정은 `.dc.html`에만 반영되었습니다.

단독실행본은 React·Pretendard 웹폰트(woff2 서브셋 184개)를 blob으로 인라인한 **디자인 툴 생성 산출물(4.3MB)** 이라 원본 편집으로는 갱신되지 않습니다. 디자인 툴에서 다시 출력해야 합니다. 재출력 전까지는 **`.dc.html`을 정본으로 봐야 합니다.**

## 화면 구조

**전역 상단 네비게이션** (모든 화면 고정)
- 좌: 팜온 로고 · 통합 대시보드 / 통계·분석 / 농업일지 / 설정 / 지원
- 우 (항상 고정): 가 큰글씨(−/+ 3단계) · 알림 · 사용자·롤 · **원격 전체 정지**

**스코프 페이지** — 스위처로 전체 ↔ 특정 농장 전환
- 통합 대시보드 A (전체): Fleet KPI · 지역 날씨 · 농장별 현황 카드 · 알림 · 오늘 작업
- 통합 대시보드 B (농장 선택): 상태 / 생육기·센서 / 로봇 / 작업·공급 / 알림

**전역 페이지** — 스위처와 무관, 항상 전 농장 대상
- 통계·분석 / 농업일지 / 설정 / 지원 / 알림

## 주요 인터랙션 (구현 시 참고)

- **원격 전체 정지**: 확인 모달 → 발동 시 상단 전체 폭 붉은 배너, 해제 전까지 자동 스케줄·원격 제어 차단. **명칭 주의** — 아래 "정지 기능 두 종류" 참고
- **가 큰글씨**: 3단계(표준 / 크게 / 아주 크게), 글자·터치영역 동시 확대, 설정 유지(localStorage). 현재 프로토타입은 `zoom` 기반이며 구현 시 rem 스케일로 전환 권장 (`design-change-spec.md`)
- **음성·도움 어시스턴트**: 우하단 고정 원형 버튼, 스크롤 무관 상주, 음성 미연동 시 텍스트 폴백
- **실시간 배치도**: 로봇·센서·탱크(양액/급수/방제)·워크스테이션 위치 표시, 클릭 시 해당 상세로 딥링크
- **로봇 임무 추가**: 기존 스케줄과 시간 충돌 검사 → 충돌 시 「기존 삭제 후 추가」/「기존 종료 후로 예약」 선택. **현재 프로토타입은 로봇 충돌만 검사** — 워크스테이션·파레트 충돌 검사 추가 필요 (FR-03)
- **농업일지**: 달력에서 날짜 선택 → 해당 일자 일지 표시 + 하단 메모 작성(기본값 당일)
- **설정**: 농장별 생육기·로봇·탱크·워크스테이션 추가 폼(이름·유형·설치 위치·연결 센서)

## 정지 기능 두 종류

디자인의 붉은 상단 버튼은 **「원격 전체 정지」** 이며 **비상정지가 아니다.** 성격이 다른 두 기능이므로 UI에서도 구분해야 한다.

| | 원격 전체 정지 (구현 대상) | 물리 비상정지 (표시만) |
|---|---|---|
| 표준 | IEC 60204-1 Stop Category 2 (운전 정지) | ISO 13850 |
| 안전등급 | 비안전등급 | 안전 기능 |
| 웹앱 조작 | 발동·해제 모두 가능 | **해제 경로를 두지 않음** |
| 담당 | 우리 팀 | 엣지·하드웨어팀 (범위 밖) |

ISO 13850은 터치스크린·화면상의 그래픽 버튼을 비상정지 장치로 인정하지 않는다. 근거와 요구사항은 `../01-requirements/non-functional.md` §2 참고. 물리 비상정지 상태 표시용 배너는 아직 미설계다 (`design-change-spec.md`).

## 데이터 계층

```
전체(Fleet) ─ 스마트팜(농장)
                ├ 생육기(재배공간) ─ 센서
                ├ 로봇 (농장 공용)
                ├ 탱크 (농장 공용)
                └ 워크스테이션 (농장 공용)
```

설계·구현은 농장 N개를 전제로 하고 **2차년도 실운영은 농장 1개**다. UI는 다농장 기준을 유지한다 (`../../00-overview.md` 다농장 전제).
