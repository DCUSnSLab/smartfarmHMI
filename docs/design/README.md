# 팜온 스마트팜 HMI v3 — 최종 디자인 전달본

RISE 피지컬 AI 기반 스마트농업 생태계 구축 사업 2차년도 · 웹앱 기반 스마트팜 HMI 프로토타입

## 파일 구성

| 파일 | 용도 |
|---|---|
| `팜온 스마트팜 HMI v3 (단독실행).html` | **더블클릭으로 바로 실행.** 외부 파일·인터넷 없이 동작하는 단일 파일. 기획·검토 공유용 |
| `팜온 스마트팜 HMI v3.dc.html` | 디자인 원본 소스. 마크업·인라인 스타일·동작 로직 전체가 들어있음. 개발 참조용 |
| `support.js` | 원본(`.dc.html`) 실행에 필요한 런타임. 같은 폴더에 함께 있어야 함 |

원본을 열 때는 `.dc.html`과 `support.js`를 **같은 폴더**에 두고 `.dc.html`을 브라우저로 열면 됩니다.

## 화면 구조

**전역 상단 네비게이션** (모든 화면 고정)
- 좌: 팜온 로고 · 통합 대시보드 / 통계·분석 / 농업일지 / 설정 / 지원
- 우 (항상 고정): 가 큰글씨(−/+ 3단계) · 알림 · 사용자·롤 · 비상정지

**스코프 페이지** — 스위처로 전체 ↔ 특정 농장 전환
- 통합 대시보드 A (전체): Fleet KPI · 지역 날씨 · 농장별 현황 카드 · 알림 · 오늘 작업
- 통합 대시보드 B (농장 선택): 상태 / 생육기·센서 / 로봇 / 작업·공급 / 알림

**전역 페이지** — 스위처와 무관, 항상 전 농장 대상
- 통계·분석 / 농업일지 / 설정 / 지원

## 주요 인터랙션 (구현 시 참고)

- **비상정지**: 확인 모달 → 발동 시 상단 전체 폭 붉은 배너, 해제 전까지 자동 스케줄·원격 제어 차단
- **가 큰글씨**: 3단계(표준 / 크게 / 아주 크게), 글자·터치영역 동시 확대, 설정 유지(localStorage)
- **음성·도움 어시스턴트**: 우하단 고정 원형 버튼, 스크롤 무관 상주, 음성 미연동 시 텍스트 폴백
- **실시간 배치도**: 로봇·센서·탱크(양액/급수/방제)·워크스테이션 위치 표시, 클릭 시 해당 상세로 딥링크
- **로봇 임무 추가**: 기존 스케줄과 시간 충돌 검사 → 충돌 시 「기존 삭제 후 추가」/「기존 종료 후로 예약」 선택
- **농업일지**: 달력에서 날짜 선택 → 해당 일자 일지 표시 + 하단 메모 작성(기본값 당일)
- **설정**: 농장별 생육기·로봇·탱크·워크스테이션 추가 폼(이름·유형·설치 위치·연결 센서)

## 데이터 계층

```
전체(Fleet) ─ 스마트팜(농장)
                ├ 생육기(재배공간) ─ 센서
                ├ 로봇 (농장 공용)
                ├ 탱크 (농장 공용)
                └ 워크스테이션 (농장 공용)
```
