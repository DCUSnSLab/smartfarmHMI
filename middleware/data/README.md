# 행정구역 역지오코딩 자료

- `bnd_dong_00_2025_2Q.zip`
  - 통계지리정보서비스(SGIS) 센서스용 행정구역경계(읍면동), 2025년 2분기
  - 좌표계: EPSG:5179
  - 주요 필드: `ADM_CD`(SGIS 8자리 코드), `ADM_NM`(행정동명)
- `kma-regions.csv`
  - 기상청 행정구역 대표 좌표와 10자리 행정구역코드

`middleware.app.region_lookup.coordinates_to_region()`은 GPS 좌표가 포함된
SGIS 경계 폴리곤을 먼저 찾고, 행정동명과 좌표 거리를 이용해 기상청 10자리
행정구역코드에 연결한다. 실행 중 외부 지도 API를 호출하지 않는다.

경계 자료를 갱신할 때는 파일명과 `BOUNDARY_ZIP` 상수를 함께 변경하고,
기상청 CSV와 코드 연결 결과를 다시 검증해야 한다. SGIS 8자리 코드와 기상청
10자리 코드는 체계가 다르므로 문자열 뒤에 `00`을 붙여 변환하면 안 된다.
